nRF52 BLE Oscilloscope

[![Watch the video](https://img.youtube.com/vi/a1N6ylp0d0E/0.jpg)](https://www.youtube.com/watch?v=a1N6ylp0d0E)

A wireless oscilloscope using the nRF52832 and Python. This project streams real-time ADC data over Bluetooth Low Energy (BLE) to a high-performance desktop GUI.

Features:

  Wireless Streaming: Sends ADC data via BLE UART service.

  4-Channel Support: Visualizes up to 4 analog pins simultaneously.

  Adjustable Sample Rate: Control sampling frequency (10Hz - 1000Hz) directly from the GUI.

  Python GUI: Built with PyQt6 and PyQtGraph for smooth, real-time plotting.

  Interactive Tools: Pause, zoom, and add data markers on the fly.

Hardware Required:

  Adafruit Feather nRF52832 (or compatible nRF52 board)

  Standard sensor or jumper wires for testing
